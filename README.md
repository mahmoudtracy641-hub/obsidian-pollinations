# Pollinations Generate — Obsidian Plugin

Generate text and images from Pollinations directly inside your notes, using your own Pollen balance.

## Install
1. Download `manifest.json` and `main.js` from this repo.
2. Create a folder named `pollinations-generate` inside `<your-vault>/.obsidian/plugins/`.
3. Put both files inside that folder.
4. In Obsidian: Settings → Community plugins → enable "Pollinations Generate".
5. Open plugin settings and paste your API key from https://enter.pollinations.ai/keys.

## Usage
- Select text (or leave nothing selected to be prompted) → run command "Generate text (selection or prompt)".
- Run command "Generate image (selection or prompt)" to embed a generated image in your note.
